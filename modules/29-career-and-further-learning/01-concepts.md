# Lesson 29.1 — Where to Go From Here

## Learning Objectives

- Understand the main career paths in cybersecurity
- Know which certifications are genuinely useful vs. hype
- Know the free resources that continue your education after this course
- Build a realistic personal development plan

## Prerequisites

The entire course — this module is a map forward, not a technical lesson.

## Career Paths

### Penetration Testing / Offensive Security
What you do: authorised security assessments, finding vulnerabilities before attackers do.
Skills this course built: Modules 11–20 (the technical track), Module 25 (reporting).
Next step: HackTheBox Pro Labs, OSCP certification, real-world practice via bug bounties.

### Defensive Security / Blue Team / SOC
What you do: monitoring, detection, incident response, hardening.
Skills this course built: Module 17 (defensive security), Module 13 (traffic analysis), Module 18 (forensics).
Next step: Blue Team Labs Online, Security Blue Team BTL1, SIEM tooling (Splunk, ELK stack).

### Application Security (AppSec)
What you do: secure code review, threat modelling, working with development teams.
Skills this course built: Module 14 (web security), Module 10 (security fundamentals), Module 22 (Python scripting).
Next step: OWASP resources, secure coding courses, reading real CVE write-ups.

### Digital Forensics & Incident Response (DFIR)
What you do: investigating compromises, preserving evidence, building timelines.
Skills this course built: Module 18 (forensics), Module 13 (traffic analysis).
Next step: SANS FOR500/FOR508 (paid but industry-leading), free CTF forensics challenges.

## Certifications Worth Knowing

| Certification | Level | Genuinely practical? | Cost |
|---|---|---|---|
| CompTIA Security+ | Beginner | Mostly theory, widely recognised by employers | ~$400 |
| eJPT (eLearnSecurity Junior PT) | Beginner-Intermediate | Practical, hands-on | ~$200 |
| OSCP (Offensive Security) | Intermediate | Highly practical, very respected | ~$1500 |
| CEH (EC-Council) | Various | More theory than practice; less respected by practitioners | ~$1000+ |

There is no substitute for actual hands-on experience. Certifications help with job applications; they don't replace the skills from doing the work.

## The Most Important Thing

Security knowledge without ethics is dangerous. Security ethics without knowledge is useless. This course tried to give you both together — the technical skills of Modules 11–20 grounded in the ethics of Module 00 and the defensive thinking of Module 17.

The security community is genuinely better when it has more people who understand both.
