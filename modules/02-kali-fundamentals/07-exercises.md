# Exercises — Module 02

1. After installing Kali, find and record: kernel version, OS pretty name, and your user's group memberships.
2. Explain in one sentence why Kali is built on Debian rather than being an entirely separate Linux distribution built from scratch.
3. Find the official Kali documentation page describing the current default (non-root) user model and summarize, in your own words, why it changed from earlier Kali versions.
