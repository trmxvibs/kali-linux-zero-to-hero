# Exercises — Module 10

1. For each of these scenarios, identify which CIA property is primarily violated: (a) a website is knocked offline by a flood of traffic, (b) an attacker reads private messages they weren't authorized to see, (c) an attacker silently changes a bank transfer's destination account number.
2. Explain, using the vulnerability/exploit/threat/risk table from `01-concepts.md`, why a critical vulnerability on an isolated, air-gapped machine with no network access might still be assigned a *low* risk rating in a real assessment.
3. Give one real (or realistic) example each of an authentication failure and a separate authorization failure — make sure they're actually different problems, not the same thing worded differently.
4. Complete the hashing and encryption exercises in `03-practical-lab.md` and explain, in your own words, why password storage uses hashing rather than encryption.
