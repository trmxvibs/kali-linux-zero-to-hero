# Challenge — Module 02

Without following a copy-paste guide, get your Kali VM to a point where:
- It's fully updated
- You've confirmed at least 3 different security tools are pre-installed and runnable (`--version` or `--help` for each, no need to use them yet)
- You've taken a labeled snapshot
- You can explain, from memory, the difference between NAT and Host-only networking modes (Module 08/Module 26 preview) and why you'll switch modes later in this course
