# Troubleshooting — Module 00

**"I don't have a terminal/Linux machine yet — can I start?"**
Yes. Module 00 and the start of Module 01 are readable without one; Kali
installation is covered in Module 02, and you'll want it before Module 01's
practical lab.

**"A link in this repository is broken."**
Please open an issue — see [CONTRIBUTING.md](../../CONTRIBUTING.md). The
repository includes an automated link checker (`tests/validate_links.py`)
but a report is still appreciated.

**"I don't understand why Module X comes before Module Y."**
See the dependency explanation in [01-concepts.md](01-concepts.md) — the
course is a dependency graph, not an arbitrary list.
