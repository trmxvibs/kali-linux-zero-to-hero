# "Lab" 00 — Locating What You Need

This module has no technical lab (there's no terminal work yet) — this is
a five-minute repository-navigation exercise instead.

## Steps

1. Open the main [README.md](../../README.md) and find the Learning Path table.
2. Open [ROADMAP.md](../../ROADMAP.md) and identify which modules are marked complete right now.
3. Open [docs/glossary.md](../../docs/glossary.md) and find the definition of "Enumeration."
4. Open [docs/getting-started/ethics-and-legal.md](../../docs/getting-started/ethics-and-legal.md) and find the exact list of what counts as a "safe target."

## Expected Result

You should be able to answer, without searching again: "Where do I find the glossary, and where do I find the full legal/ethics policy?"
