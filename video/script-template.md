# Video Script Template

Reusable structure for every video in this course. Copy this for each new
script. Keep tone honest and educational — no "become a hacker in 7 days"
framing.

```text
Hook                    — one real question/problem this video answers
What you will learn     — 2-4 bullet objectives, matching the lesson's Learning Objectives
Prerequisites           — what the viewer should already know/have set up
Concept explanation     — plain language first, then technical detail
Demonstration           — screen recording matching 04-commands.md exactly
Lab                     — walk through 03-practical-lab.md live
Common mistakes         — from 05-troubleshooting.md
Security perspective    — from 06-security-notes.md
Exercise                — point viewer to 07-exercises.md, don't solve it on screen
Recap                   — 2-3 sentence summary
Next lesson             — name and link the next module/lesson
```
