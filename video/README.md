# Video Course Integration

This course is designed so a learner can either watch the video series or
read the GitHub documentation alone — either path is complete on its own.

**No videos are being produced for now.** This is a deliberate, current
decision, not an oversight — effort is going into deepening the written
modules first. This folder's mapping format is kept as a template for
if/when video production starts later; it does not imply videos are coming
soon.

See [course-map.md](course-map.md) for the mapping table and
[script-template.md](script-template.md) for the required script structure.
