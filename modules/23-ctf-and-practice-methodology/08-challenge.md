# Challenge — Module 23

Create your own beginner-level CTF challenge:
- Choose a category (Web, Forensics, or Crypto)
- Design a challenge with a hidden flag — e.g., embed a flag inside a file's metadata, hide it in a base64-encoded field in a web response, or encrypt it with a reversible cipher
- Write a challenge description a beginner could follow
- Solve your own challenge to confirm it works
- Write the solution/write-up separately

This is more difficult than solving a challenge — designing a good puzzle requires understanding why the technique works, which is a deeper form of the same knowledge.
