# Challenge — Module 14

Extend `labs/web-security/sqli_demo.py` into a small interactive tool:
- Accept a username and password from the command line (`input()` or `argparse`)
- Run both the vulnerable and safe versions against the same input
- Print a clear side-by-side comparison of the two results
- Add at least one more injection payload of your own design, explain in a comment what you expect it to do, then verify your prediction by running it — following the exact discipline this module's own lab used when a prediction turned out to be wrong

This is a good opportunity to practice the same "test your assumption, don't just trust it" habit that shaped this module's own content.
