# Challenge — Module 05

Write a short Bash script (building on Module 03) that:
- Takes a username as an argument
- Prints that user's UID, primary group, and all supplementary groups in a clean, readable format
- Handles the case where the username doesn't exist, with a clear error message and a non-zero exit code

Test it against your own username and against a deliberately nonexistent username to confirm both paths work.
