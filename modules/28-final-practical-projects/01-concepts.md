# Lesson 28.1 — Capstone Projects: Putting It All Together

## Learning Objectives

- Apply every skill from the course in a single, cohesive, authorized lab exercise
- Produce a professional-quality report from start to finish
- Identify remaining gaps in your own knowledge

## Prerequisites

Modules 00–27 (the entire course).

## Concept

The capstone project is not a new technique — it is the complete workflow of this course, executed as a single, coherent exercise:

```
Scope Definition
     ↓
Isolated Lab Setup (Module 26)
     ↓
Reconnaissance (Module 11)
     ↓
Enumeration (Module 12)
     ↓
Traffic Analysis (Module 13)
     ↓
Vulnerability Identification (Module 15)
     ↓
Controlled Validation in Lab (Module 20)
     ↓
Evidence Collection + Hashing (Module 18)
     ↓
Risk Assessment (Module 10, 15)
     ↓
Professional Report (Module 25)
```

The difference between this and the individual module labs is continuity: you perform each step with the next step in mind, and the output of each step feeds the next, until you have a complete, documented engagement against your Metasploitable VM.

## The Three Capstone Projects

### Project A — Network Assessment

Full reconnaissance, enumeration, and vulnerability assessment of Metasploitable 2. Output: a professional report following Module 25's template.

### Project B — Web Application Assessment

Full assessment of DVWA (Damn Vulnerable Web Application) — set it up in your lab (see Module 26 for guidance), identify vulnerabilities, confirm findings, report with evidence.

### Project C — Bash/Python Security Tool

Build one of Module 21 or 22's challenge tools to completion — tested, documented, with a proper README. This demonstrates engineering skill alongside security knowledge.

## How to Know You're Done

A capstone project is complete when:
- Someone who wasn't there can follow what you did purely from your documentation
- Every finding has: evidence, a severity, a reproducible path, and a remediation
- Your report passes Module 25's self-review checklist
