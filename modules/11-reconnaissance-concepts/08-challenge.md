# Challenge — Module 11

Using only Nmap flags (no external tools), produce a scan that:
- Only targets TCP ports 1-1000
- Uses service/version detection
- Uses a "polite" timing template
- Skips host-discovery ping (assume ICMP is blocked)
- Saves output to a file in a normal, readable text format

Then explain, in your own words, why you'd choose these specific flags for a real (authorized) fragile production target versus your lab VM.
