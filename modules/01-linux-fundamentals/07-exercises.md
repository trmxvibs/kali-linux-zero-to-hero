# Exercises — Module 01

1. Create a directory `~/ex01` containing five files named `file1.txt` through `file5.txt`, each containing a different single word.
2. Using `grep`, find which file contains the word you chose for `file3.txt` — but do it by searching for the word, not the filename.
3. Use `find` to list every `.txt` file under `~/ex01` modified today.
4. Start a long-running command (`sleep 300 &`), then use `ps aux` to find its PID, and `kill` it.
5. Explain, in one sentence, the difference between `kill` and `kill -9`.

## Self-Check

You should be able to do all five without looking at `04-commands.md`. If you need to check twice for the same command, that's fine — but a third time means slow down and re-read `01-concepts.md`.
