# Exercises — Module 00

These have no lab environment requirement — they're a readiness check.

1. In your own words (2–3 sentences), explain why this course teaches networking (Module 08) before reconnaissance tools (Module 11).
2. List three things that would count as a "safe target" for a lab in this course, and one thing that would not.
3. Find the `06-security-notes.md` file in this module and locate the exact sentence that defines the course's "One Rule." Copy it into your own notes — you'll want it memorized, not looked up.
4. Skim the main [README.md](../../README.md) learning path. Identify which module you expect to find the most difficult, based on your current background, and why.

## Self-Check

If you can't answer that from memory, re-read `06-security-notes.md` before continuing.
