# Challenge — Module 01

Without being told the exact commands, figure out how to:

1. Find the 3 largest files under `/var/log` (hint: `man du`, `man sort`, and pipes `|` — piping is introduced properly in Module 03, but see if you can guess it).
2. Count how many files in your home directory were modified in the last 24 hours.
3. Find every file in your home directory that is *not* readable by other users.

There is no single "correct" one-liner — if your command produces the right answer and you can explain why it works, you've succeeded. Solutions approach (not exact commands) is discussed at the start of Module 03 once pipes are formally introduced.
